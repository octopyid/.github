# Octopy ID

Octopy ID is a software engineering practice based in Indonesia. It covers backend development, Linux server work, and web applications. Most projects are open source and maintained under this organization.

Website: https://www.octopy.dev
Contact: hello@octopy.dev

## Maintained projects

- [LaraPersonate](https://github.com/octopyid/LaraPersonate): Log in as another user in Laravel for local development and support checks.
- [filament-palette](https://github.com/octopyid/filament-palette): Color palette switcher for FilamentPHP admin panels.
- [filament-tabify](https://github.com/octopyid/filament-tabify): Tabbed widgets for Filament dashboards.
- [rune](https://github.com/octopyid/rune): CLI-first task runner. Define project tasks as commands that work with any stack.
- [laravel-inotify](https://github.com/octopyid/laravel-inotify): File system watcher for Laravel development.
- [GPhotoCLI](https://github.com/octopyid/GPhotoCLI): Command line tool to upload and organize photos in Google Photos.
- [OctopyFramework](https://github.com/octopyid/OctopyFramework): Lightweight PHP framework with a Laravel-style structure.

## Stack

PHP with Laravel and Filament, Go for CLI tools, TypeScript and Vue (Nuxt) for frontend, Linux and Docker for servers.

## How we work

- Code is written to be read and maintained.
- Documentation explains intent, not just usage.
- Repositories carry a clear status: stable, experimental, or in progress.

## Contact

For questions about a specific repository, open an issue in that repository. For everything else, email hello@octopy.dev.
